# Battery Design and Management System (BMS) Modeling

Comprehensive simulation and modeling framework for Battery Energy Storage Systems (BESS) and Battery Management Systems (BMS), developed in MATLAB, Simulink, and Simscape.

## Overview
This repository contains end-to-end design, simulation, and validation workflows covering battery cell characterization, equivalent circuit modeling (ECM), state estimation (SOC), electro-thermal dynamics, and pack-level scaling.
